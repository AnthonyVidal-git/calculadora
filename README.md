# 🧮 Calculadora

Uma calculadora completa, animada e bonita, feita com **HTML, CSS e JavaScript puro**: sem frameworks e sem `eval`.

## ✨ Recursos

- **Modo básico e científico**: `sin`, `cos`, `tan`, `log`, `ln`, `√`, `xʸ`, `x²`, `n!`, `π`, `e`
- **DEG / RAD** para funções trigonométricas
- **Parênteses, porcentagem e multiplicação implícita** (`2π`, `3(4+1)`)
- **Prévia do resultado** em tempo real enquanto você digita
- **Histórico** salvo no navegador (clique num item para reutilizar)
- **Tema claro e escuro**
- **Suporte ao teclado**: números, `+ - * / ^ ( ) %`, `Enter`, `Backspace`, `Esc`
- **Animações**: fundo com gradientes flutuantes, efeito glassmorphism, ripple nos botões, confete ao calcular e "tremida" em erro
- Respeita `prefers-reduced-motion`
- Formatação no padrão brasileiro (`1.234,56`)

## 🚀 Como usar

Abra o `index.html` no navegador. Só isso.

```bash
git clone https://github.com/<seu-usuario>/calculadora.git
cd calculadora
start index.html
```

## 🗂️ Estrutura

```
index.html   → estrutura da calculadora
style.css    → visual, temas e animações
script.js    → parser de expressões, histórico e interações
```
